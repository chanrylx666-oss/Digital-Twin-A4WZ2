# Blender 模型整理与导出

## 学习目标

把一整台设备模型整理成“固定件不动、运动件可以独立运动”的资源。数字孪生能否正确运动，首先取决于分件和轴心，而不是代码。

## 1. 先列出机械运动关系

在 Blender 操作前建立分件表：

| 机构 | 固定部分 | 运动部分 | 运动类型 | 轴心位置 |
|---|---|---|---|---|
| 转臂 | 底座和立柱 | 升降部分 | 直线 | 升降导轨方向 |
| 转臂 | 升降部分 | 旋转部分 | 旋转 | 中央回转轴 |
| 夹具 | 转臂 | 8 个夹爪 | 直线 | 各夹爪自身局部轴 |
| 上料台 | 固定座 | 回转盘 | 旋转 | 回转盘中心 |
| 测速模块 | 固定座 | 水平移动部分 | 直线 | 导轨方向 |
| 测速模块 | 水平部分 | 探头升降部分 | 直线 | 探头升降方向 |
| 去重机构 | 固定座 | 钻头/滑台 | 直线或旋转 | 实际机械轴线 |

本仓库 `Models/` 已按类似思路拆成多个 `.blend` 文件，例如转臂升降部分、转臂旋转部分、夹爪、上料回转部分和测量模块。

## 2. 统一单位和方向

1. 在 Blender 的 **Scene Properties → Units** 选择 `Metric`。
2. 推荐约定 `1 Blender Unit = 1 m`；若 CAD 以毫米导入，通常需要整体缩放 `0.001`。
3. 选择模型，按 `Ctrl + A`，应用 **Rotation & Scale**。
4. 不要在确认装配位置前随意应用 Location，否则可能丢失装配参考。
5. 记录设备的上、前、右方向，后续 Godot 中必须保持一致。

关键不是强制使用某一种单位，而是所有零件采用同一比例。当前项目的坐标值来自原始模型比例，因此复刻现有场景时不要单独缩放某个部件。

## 3. 分离运动件

如果 CAD 导入后是一整个对象：

1. 进入 Edit Mode。
2. 选中某个完整运动部件。
3. 按 `P → Selection` 分离为独立对象。
4. 为对象命名，例如 `Arm_Lift`、`Arm_Rotate`、`Gripper_01`。
5. 重复操作，直到每个需要独立运动的部件都是独立对象。

零件名称应表达机械职责，不要保留 `Cube.001` 这类名称。稳定名称便于 Godot 节点绑定和后续排错。

## 4. 设置旋转轴心

旋转动画绕对象 Origin 进行。轴心错误时，代码再正确也会出现偏心旋转。

1. 选中回转轴或中心孔的几何位置。
2. 使用 `Shift + S → Cursor to Selected` 将 3D Cursor 放到轴心。
3. 回到 Object Mode。
4. 执行 **Object → Set Origin → Origin to 3D Cursor**。
5. 将旋转角度临时改为 `10°`，确认模型绕正确轴心运动。

对复杂机构，推荐增加一个 Empty 作为枢轴，把可见模型设为 Empty 的子对象；导入 Godot 后对应一个 `Node3D` 旋转枢轴。

## 5. 设置直线运动局部轴

夹爪和滑台通常沿自身局部轴移动。打开 Blender 的 Local Transform Orientation，确认：

- 哪个轴是升降方向；
- 哪个轴是水平移入方向；
- 正方向是靠近工件还是远离工件。

将结果记录在表中。例如：

| 节点 | 运动轴 | 闭合/下降方向 |
|---|---|---|
| Gripper 1 | Local Z | `-Z` |
| Gripper 2 | Local Z | `+Z` |
| Left detector | Local Z | `-Z` 或项目实际方向 |

这张表将直接决定 Godot 中 `GetGripperOffset()` 和检测机构目标坐标的正负号。

## 6. 导出与验证

推荐导出 `.glb`：

1. 选择单个部套或一组有明确父子关系的对象。
2. `File → Export → glTF 2.0`。
3. 格式选 `GLB`，勾选 Selected Objects。
4. 导出后重新导入一个空 Blender 场景，验证比例、方向、轴心和父子关系。

也可以直接使用 `.blend`，但目标电脑需具有兼容的 Blender 导入环境；用于分享教学时，`.glb` 通常更稳定。

## 完成检查

- 固定件与运动件已分离。
- 旋转件 Origin 位于真实轴心。
- 8 个夹爪可以分别选中。
- 所有部件单位和比例一致。
- 单独测试 `10°` 旋转和少量平移时方向正确。
