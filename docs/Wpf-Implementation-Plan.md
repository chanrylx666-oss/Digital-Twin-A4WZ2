# Digital-Twin-A4WZ2 WPF 第一阶段实施计划

## 目标

创建可由 Visual Studio 2026 直接打开、编译和运行的 `.NET 10` WPF 解决方案。首个可运行版本默认使用模拟设备，演示四工位“全部准备后同时启动、各自完成、全部终态后统一转位”的完整节拍，并预留真实 PLC、采集卡和 Godot 的适配接口。

## 实施任务

1. 创建 `DigitalTwinA4WZ2.sln`、`src` 与 `tests` 下的分层项目，并配置项目引用。
2. 先在领域测试中定义四工位屏障、故障终态和转位许可规则，再实现领域模型。
3. 先在信号处理测试中定义确定性模拟波形和 1X 幅相提取结果，再实现采集模型。
4. 先在应用测试中定义自动周期状态转换，再实现模拟流程协调器。
5. 实现基础设施服务：日志、报警、JSON 配方/设置、Modbus TCP 连接骨架和 Godot 状态桥接。
6. 实现 WPF MVVM 主界面：总览、四工位卡片、模拟控制、配方、设置、报警与日志。
7. 默认使用 `Simulation` 配置，加入启动、停止、复位、故障注入和时间倍率功能。
8. 增加中文 XML 注释、README、连接参数与数据格式说明。
9. 执行 `dotnet test`、`dotnet build` 和启动冒烟检查，记录代码审查与交付结果。
10. 在 WPF 增加“数字孪生”页，由页面自动定位、启动并嵌入 Godot 运行窗口；找不到 Godot 时显示明确配置提示。

## 验证标准

- Visual Studio 打开 `DigitalTwinA4WZ2.sln` 后，启动项目为 `DigitalTwinA4WZ2.Hmi`。
- 在无 PLC、无传感器、无采集卡环境下能够运行。
- 点击“启动自动循环”后四工位同时加工；快工位等待慢工位；全部结束后执行模拟转位并进入下一周期。
- 无料、测量失败和钻孔失败属于允许转位的终态，并产生对应提示。
- 同一随机种子产生相同模拟信号。
- 所有自动化测试通过，解决方案无编译错误。
