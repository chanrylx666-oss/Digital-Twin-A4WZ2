# Digital-Twin-A4WZ2 WPF 第一阶段代码审查

## 审查结论

第一阶段实现与 `Wpf-Implementation-Plan.md` 的目标一致，未发现阻断交付的 Critical 或 Major 问题。

## 已核对内容

- WPF、领域、应用、基础设施、PLC、采集、信号处理、Godot 桥和模拟器之间引用方向清晰。
- ViewModel 不直接读写 PLC 寄存器；设备访问通过接口隔离。
- 四工位全部准备、并行完成和统一转位屏障由领域模型集中判断。
- 无料、测量失败和钻孔失败允许转位；PLC 断线和测速丢失阻断转位。
- 模拟采集带 `IsSimulated=true`，使用固定随机种子。
- Modbus TCP 客户端校验事务号、功能码、长度和异常响应。
- 模拟服务器只绑定回环地址，默认端口与真实 PLC 的 502 分离。
- 配方和设置保存使用临时文件后原子替换。
- 日志和运行数据写入 `%LOCALAPPDATA%`，不污染项目目录。
- Godot 场景和模型文件保持独立；`ReView.csproj` 已排除 WPF 的 `src/`、`tests/`，避免两个 C# 工程相互混编。
